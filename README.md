# 🤖 Super Neural Assistant

![Python](https://img.shields.io/badge/Python-3.10+-blue?logo=python)
![License](https://img.shields.io/badge/License-MIT-green)
![Status](https://img.shields.io/badge/Status-Active-success)

Интеллектуальный голосовой ассистент с распознаванием лиц, эмоций и определением "свой-чужой" на Python.
[![Демонстрация работы Super Neural Assistant](https://img.[youtube.com/vi/ВАШ_ID_ВИДЕО/maxresdefault.jpg](https://www.youtube.com/shorts/6t07YOtpqkU))](https://www.youtube.com/shorts/6t07YOtpqkU))](https://www.youtube.com/watch?v=ВАШ_ID_ВИДЕО)
*Нажмите на картинку, чтобы посмотреть видео-демонстрацию проекта*

### 🎭 Распознавание лиц и эмоций
- Идентификация знакомых лиц по технологии **FaceNet** через **DeepFace**
- Анализ 7 базовых эмоций (радость, грусть, злость, удивление, страх, отвращение, спокойствие)
- Система "свой-чужой" на основе косинусного сходства эмбеддингов
- Персонализированное приветствие с учётом настроения пользователя

### 🎤 Голосовое управление
- Распознавание речи через **Vosk** (модель `vosk-model-ru-0.42`)
- Озвучка ответов через **Edge-TTS** (голос `ru-RU-DmitryNeural`)
- Идентификация говорящего по голосу через **Resemblyzer**
- Wake words: "Джарвис", "Алиса", "Компьютер", "Ассистент"

### 🧠 Интеллектуальные функции
- Поиск информации в интернете через **DuckDuckGo**
- Генерация ответов через **GPT-4o-mini** (g4f)
- Контекст диалога (память последних 10 сообщений)
- Система команд для управления ПК

### 💻 Управление системой (голосом)
- Открытие приложений: браузер, YouTube, калькулятор, блокнот, Word, Excel, PowerPoint, Paint, проводник
- Веб-сервисы: Google, Wikipedia, GitHub, переводчик, карты
- Системные команды: блокировка экрана, выключение, перезагрузка
- Математические вычисления
- Заметки, таймеры, напоминания
- Развлечения: шутки, случайные числа, монетка, кубик, интересные факты

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│   Микрофон   │────▶│  Vosk (STT)  │────▶│  Chat Queue  │
└──────────────┘     └──────────────┘     └──────┬───────┘
                                                  │
┌──────────────┐     ┌──────────────┐             ▼
│   Камера     │────▶│  DeepFace    │     ┌──────────────┐

                                                  │
                     ┌──────────────┐             ▼
                     │  Edge-TTS    │◀────────────┘
                     │  (озвучка)   │
                     └──────────────┘
```

## 📦 Установка

### 1. Клонируйте репозиторий
```bash
git clone https://github.com/kotsolga3883-arch/super-neural-assistant.git
cd super-neural-assistant
```

### 2. Создайте виртуальное окружение (рекомендуется)
```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate
```

### 3. Установите зависимости
```bash
pip install -r requirements.txt
```

### 4. Скачайте модель Vosk
Скачайте русскую модель `vosk-model-ru-0.42` (1.8 ГБ) с [официального сайта Vosk](https://alphacephei.com/vosk/models) и распакуйте в корень проекта.

### 5. Подготовьте базу лиц
Создайте папку `known_faces/` и поместите в неё фотографии в структуре:
```
known_faces/
├── Ivan_Ivanov/
│   ├── photo1.jpg
│   └── photo2.jpg
├── Olga_Petrova/
│   └── photo1.jpg
```

### 6. Запуск
```bash
python main.py
```

## 🔧 Зависимости

Все необходимые библиотеки указаны в `requirements.txt`. Основные:
- `opencv-python` — работа с камерой
- `deepface` — распознавание лиц и эмоций
- `vosk` — распознавание речи
- `edge-tts` — синтез речи
- `resemblyzer` — идентификация по голосу
- `g4f` — доступ к GPT-моделям
- `ddgs` — поиск в DuckDuckGo

## 🎯 Использование

- **Q** — выход из программы
- **R** — обновить кэш лиц
- **C** — пересоздать базу лиц
- **V** — записать образец голоса (3 сек)

### Примеры голосовых команд
- "Открой браузер" / "Открой YouTube"
- "Который час?" / "Какое сегодня число?"
- "Посчитай 25 умножить на 4"
- "Расскажи шутку" / "Подбрось монетку"
- "Запиши заметку: купить молоко"
- "Погугли нейронные сети"
- "Заблокируй экран"

## 📊 Технические детали

- **Модель распознавания лиц:** FaceNet (через DeepFace)
- **Порог "свой-чужой":** 85% (cosine similarity)
- **Порог распознавания голоса:** 75%
- **Частота дискретизации:** 16000 Гц
- **Модель Vosk:** `vosk-model-ru-0.42` (большая, высокая точность)
